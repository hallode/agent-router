# AGENTS.md

Guidance for coding agents working in this repository. `README.md` is the
user-facing doc; this file covers what you need to change the code safely.

## What this is

agent-router picks a model for a Claude Code or Codex task without spending a
model call on the decision. It is plain Bash + `jq` (plus one Python helper).
There is no build step.

## Commands

```sh
bash tests/run.sh            # hermetic suite: classifier, governor, hooks, wrappers, installer
bash tests/audit-readme.sh   # documented entry points exist; README has no stale paths
bash tests/verify-install.sh # checks the LIVE installs under ~/.claude and ~/.codex
bash install.sh [--with-agents]
```

Run a single area by reading `tests/run.sh`: it is one flat script with `echo
"== section =="` headers and `eq`/`ok`/`bad` helpers, not a framework. Add new
cases next to the section they belong to.

Inspect a decision from the checkout without launching anything (keep state
out of the repo; `cxr` also probes your real Codex quota via `codex-quota`):

```sh
export ROUTER_HOME=$PWD ROUTER_CONFIG=$PWD/config.example.json ROUTER_STATE=$(mktemp -u)
bash bin/ccr -n "find the handler"
bash bin/cxr -n "implement the endpoint"
```

## Architecture

One source checkout installs **two isolated runtimes**. This split is the
central invariant; most of `install.sh` and `tests/verify-install.sh` exists to
enforce it.

| | Claude runtime (`~/.claude/router`) | Codex runtime (`~/.codex/router`) |
|---|---|---|
| launcher | `bin/ccr` | `bin/cxr` (+ `bin/codex-quota`) |
| controls | `bin/claude-router` → `bin/router` | `bin/codex-router` → `bin/router` |
| hooks | `hooks/claude-{subagent,advisor,session}.sh` | `hooks/codex-advisor.sh` |
| host lib | `lib/claude-model.sh`, `lib/claude-agent.sh` | `lib/codex-budget.sh` |
| shell | `shell/claude.zsh` | `shell/codex.zsh` |

Shared libs copied to both: `lib/config.sh`, `classify.sh`, `governor.sh`,
`workspace.sh`, `activity.sh`. `bin/agent-router` is the only cross-host file;
it is installed to `~/.local/bin` and only reads both runtimes' `activity.jsonl`.

Never let a Claude file reference Codex or vice versa: `verify-install.sh`
greps each installed runtime for the other host's name and fails on a match.
Shared libs must therefore stay host-neutral.

Decision pipeline:

1. `classify.sh` — regex heuristics → `trivial | execution | reasoning`.
   Precedence: `agent_type_tiers` map > reasoning signal > trivial signal >
   `execution` default. Patterns include Indonesian keywords; keep them.
2. `governor.sh` — budget state `NORMAL → CONSERVE → CRITICAL → DEPLETED` in
   `state.json`. Sources: manual override > recorded rate limit (decays after
   `ROUTER_LIMIT_TTL`) > optional `quota.command`.
3. Host mapping — Claude: `degrade[state][tier]` (`claude-model.sh`). Codex:
   lower the tier by state (`codex-budget.sh`), then take `codex_chains[tier]`;
   later chain entries are rate-limit fallbacks in `cxr`, never a cheaper step.
4. `config.sh` — a project's nearest `.agent-router.json` (walking up, stopping
   at `$HOME`) is deep-merged over the host config into a temp file for that
   call only.

Hooks: `claude-subagent.sh` (PreToolUse:Agent) is the only place a model is
enforced, by rewriting `tool_input.model`. It skips `fork`, honours the `!!`
bypass prefix, and defers to an agent file that declares its own `model:`.
The advisor/session hooks only inject context, record activity, and tell the
user once per session (`systemMessage`, deduped via `sessions/<sid>.hints`)
when the session model is too large or too small for a prompt. No hook can
change a running session's model.

Effort: Claude's `effort` map applies to `ccr --effort` and the `/effort`
suggestion; subagent effort lives in each `agents/router-*.md` `effort:`
frontmatter because the Agent tool has no effort field. Codex roles are TOML
files generated by `codex_write_agents` (`lib/codex-budget.sh`) into
`~/.codex/agents/`; they carry a marker line, and only marked files are ever
rewritten.

## Conventions and invariants

- **Bash 3.2 compatible** (macOS `/bin/bash`): no associative arrays, no
  `${v,,}`, no `mapfile`.
- **Hooks fail open.** Every error path exits 0 with no output. A broken router
  must never block a tool call or a prompt.
- **Exit 126 means "router could not start".** The zsh wrappers fall back to the
  native CLI only on 126, never on a deliberate refusal (e.g. `cxr`'s workspace
  guard). Preserve this in any launcher change.
- **jq `//` treats `false` as empty.** Use `if has("k") then .k else D end` for
  boolean config keys (see `enforce` in `claude-subagent.sh`).
- Every entry point reads `ROUTER_HOME`, `ROUTER_CONFIG`, `ROUTER_STATE`,
  `ROUTER_LOG`, `ROUTER_ACTIVITY`, `ROUTER_SESSIONS`, `CODEX_AGENTS_DIR` from
  the environment so tests can redirect them. New state files need the same override.
- Write state atomically (`tmp.$$` then `mv`).
- Comments explain *why* (a constraint, a past failure), not what. Match that.
- `config.example.json` is a combined template; `install.sh` strips it into
  host-specific configs with `jq del(...)`. A new top-level key must be routed
  to the right host there, and existing user configs are never overwritten.
- Agent role names are `router-scout|builder|inspector|navigator` and nothing
  else. Keep this repo's vocabulary its own: no role names, terms, or phrasing
  lifted from other agent tools, in code, config, tests, or docs.
- When adding a file under `bin/`, `hooks/`, `lib/`, or `shell/`, update
  `install.sh`, `tests/verify-install.sh`, and `tests/audit-readme.sh` together.

## Tests

`tests/run.sh` is hermetic: it points `ROUTER_*` at a temp dir, builds fixture
git repos, stubs `codex` on `PATH` to exercise rate-limit failover, and runs
`install.sh` into an isolated tree. It must never touch real `~/.claude` or
`~/.codex`. `verify-install.sh` is the opposite — it checks the live machine and
is expected to fail on a machine without both hosts installed.

## Commits

History uses `type: description` (feat, fix, docs, refactor, test, chore), with
the subject stating the problem or outcome, e.g.
`fix: never turn a deliberate refusal into a real run`.
